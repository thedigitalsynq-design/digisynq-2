Module Directory

Core Coordination Protocols & Modules

Production Grade
Core 01 Synq Registry Service (SRS)

Cryptographic directory maintaining authenticated identifiers for stages, rental houses, guilds, and production entities.

Core 02 Bilateral Matching Engine (BME)

Evaluates spatial clearances, 3-phase power requirements, acoustic criteria, and schedule overlaps under zero-knowledge privacy.

Core 03 Escrow Settlement Gateway (ESG)

API conduit to licensed partner banks routing earnest funds, hold deposits, and milestone draw releases upon cryptographic verification.

Core 04 Milestone Telemetry Oracle (MTO)

Ingests signed digital call-sheets, Brompton gen-lock sync diagnostics, and stage door badges to confirm milestone execution.

Intelligence 01 Dynamic Capacity Oracle (DCO)

Aggregates dark-window stage calendar telemetry to forecast regional availability and market rate trends across global hubs.

Intelligence 02 Reputation Trust Oracle (RTO)

Non-custodial algorithmic scoring calculating payment timeliness, gear condition at wrap, and on-schedule stage release.
